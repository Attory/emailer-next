# Installation

Use the finished 1.2.0 [beginner guide](guides/emailer-ripe-install.md), including real installer screenshots and recovery instructions. HTML and PDF versions are linked from the [documentation index](guides/README.md).

The self-contained signed setup file performs native provisioning and verification. A testing mailbox, Composer, manual environment files and handwritten services are not customer prerequisites. For exceptional hosts see the [operator reference](guides/emailer-ripe-operator.md). Historical release reports remain in the repository history and their published releases.
